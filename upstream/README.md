# Original design

**[Giffin Grip Clone by vpxr on Printables](https://www.printables.com/model/624664-giffin-grip-clone)** is the source for this adaptation. Its [original description](original-description.pdf) is provided for reference. The smaller-version STL inputs and original assembly STEP are in [source/](source/). These source files have not been scaled or mirrored. For the finished CORE One files use the [repository print guide](../README.md).

The original author included a STEP update dated December 5, 2025 and licensed the model under [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/). The upstream instructions refer to both whole and segmented options and do not specify an O-ring size. The 13 × 2 mm ring in this fork is for its redesigned axle.
